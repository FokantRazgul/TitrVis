## Datasets and their provenance

| dataset | source | licence / terms | where |
| --- | --- | --- | --- |
| CIE 1931 2° standard observer x̄, ȳ, z̄ (5 nm) | CIE 15:2004 Table T.4, as distributed by CVRL and mirrored in colour-science (`colour/colorimetry/datasets/cmfs.py`, BSD-3-Clause), accessed 2026-09-05 | CIE tables are public reference data; colour-science mirror BSD-3-Clause | `src/chemistry/data/cie.ts` (generated by `scripts/generate-cie-data.py`) |
| CIE Standard Illuminant D65 (5 nm) | CIE 15:2004 Table T.1 via colour-science (`illuminants/sds.py`) | as above | `src/chemistry/data/cie.ts` |
| Acid/base dissociation constants (74 substances) | CRC Handbook of Chemistry and Physics, 97th ed. (2016), Section 5 | reference values transcribed for scientific use; attribution given per entry | `src/chemistry/data/substances.data.ts` |
| Molecular formulae, weights, CIDs, SMILES | PubChem (NIH/NLM), https://pubchem.ncbi.nlm.nih.gov/, accessed 2026-09-05 | public domain (US Government work) | substances and indicators data files |
| Indicator pKa, ranges, colours, λmax | R. W. Sabnis, *Handbook of Acid-Base Indicators*, CRC Press, 2008 (secondary compilation) | reference values transcribed; attribution per entry | `src/chemistry/data/indicators.data.ts` |
| Indicator spectra | reconstructed in this project from the descriptors above (Gaussian bands) — not measured data | project licence | generated at load in `src/chemistry/indicators.ts` |
| Flask dimensions | ISO 1773 narrow-neck Erlenmeyer flask sizes | standard dimensions | `src/simulation/flaskGeometry.ts` |

No fonts, textures, HDR environment maps or audio assets are bundled: the environment is
procedural, the sound is synthesised with the Web Audio API and the molecule drawings are produced
at run time from SMILES.

- Three.js, React, drei, Zustand, Plotly, smiles-drawer: MIT — retain copyright notices in the

  `legalComments` handling of the vendor chunks; the `node_modules/*/LICENSE` files list the
  holders).

  `src/chemistry/data/cie.ts` credits the source.
- PubChem: cite "PubChem, National Library of Medicine" (done in the data file headers and the
  Indicator panel, which shows the CID).
